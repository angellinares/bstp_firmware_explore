BeatStep Pro mods

Unofficial changes to Arturia's BeatStep Pro firmware 2.0.1.6. Not made or supported by Arturia. Source code, changelog and how it is tested: github.com/angellinares/bstp_firmware_explore.

Modified firmware can leave your BeatStep Pro unusable, and you install it at your own risk. Before installing anything from here, install Arturia's own 2.0.1.6 file once with MIDI Control Center, so you know the way back works on your unit.

Back up all your projects first. Use MIDI Control Center to save every project on the unit to your computer before you install custom firmware. A mod changes how patterns are stored, and a fault could damage or erase them.

Have you backed up your projects?

Before you install custom firmware, save every project on the BeatStep Pro to your computer with MIDI Control Center. A mod changes how patterns are stored, and a fault could damage or erase them.

Installing, and going back

Install the downloaded file with MIDI Control Center, the same way as an Arturia update. To go back, install Arturia's original file the same way. If the unit does not start, hold PLAY + STOP + RECORD while switching it on to reach the updater.

The file name and the firmware inside both carry the mod and its version, so a file can always be traced to the entry in its changelog above.
